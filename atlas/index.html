放文件的原则

能发给客户、能支持判断、能复盘来源的文件可以进入公开资料库。内部草稿、原始后台数据、客户私密信息、未确认推断不要公开。

公开可发敏感不放证据优先
File Structure

文件结构：入口、报告、调研资料和资产分开，后续才不会乱。

现有报告 URL 不移动；新增资料和新品牌研究都进 `atlas/` 下的结构。

`/atlas/`

Atlas 项目总入口。展示报告库、资料库、入口页和文件结构。

`/atlas/research/`

公开调研资料库。后续可按品牌建立子目录或独立研究页。

`/*.html`

现有品牌报告继续保留在根目录，确保已经发出的 GitHub Pages 链接不失效。

`/assets/`

存放 favicon、品牌 logo、可公开截图和报告依赖素材。
